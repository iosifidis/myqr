# 📱 QR Vault - Διαχειριστής & Σαρωτής QR Codes

Μια σύγχρονη, ταχύτατη και responsive Progressive Web App (PWA) εφαρμογή για σκανάρισμα, αποθήκευση, οργάνωση και διαχείριση QR codes, έτοιμη για φιλοξενία στο **Netlify** και σύνδεση με Cloud Database (**Supabase**).

---

## ✨ Κύρια Χαρακτηριστικά

1. **📷 Σκανάρισμα QR**:
   - Ζωντανή σάρωση με την κάμερα του κινητού ή υπολογιστή με στόχαστρο και λέιζερ ανίχνευσης.
   - Υποστήριξη φακού (Torch/Flashlight) σε συμβατά κινητά.
   - Δυνατότητα επιλογής & σκαναρίσματος από έτοιμη φωτογραφία/screenshot στη συλλογή.
   - Ηχητική & απτική ειδοποίηση (beep & δόνηση) κατά την επιτυχή αναγνώριση.

2. **💾 Αποθήκευση στη Βάση**:
   - Αποθήκευση με **Όνομα** και αυτόματη αναγνώριση περιεχομένου (URL, WiFi, Email, Τηλέφωνο, Κείμενο).
   - **Διπλή υποστήριξη**: Άμεση λειτουργία χωρίς κανένα setup με τοπική μνήμη (`LocalStorage`/`IndexedDB`) ΚΑΙ δυνατότητα σύνδεσης με **Cloud Supabase** για συγχρονισμό σε όλες τις συσκευές.

3. **📋 Λίστα & Εμφάνιση / Επεξεργασία**:
   - Εμφάνιση όλων των QR με όνομα, badge τύπου και ημερομηνία.
   - Πάτημα πάνω σε οποιοδήποτε QR ανοίγει πλήρη προβολή:
     - Δυναμική παραγωγή της εικόνας QR Code σε υψηλή ανάλυση.
     - Λήψη σε εικόνα PNG (`Download`).
     - Άμεσο άνοιγμα συνδέσμου (`Open Link`).
     - Αντιγραφή περιεχομένου (`Copy`).
     - Επεξεργασία ονόματος ή περιεχομένου (`Edit`).
     - Διαγραφή (`Delete`).

4. **⚡ Αλλαγή Σειράς & Άμεση Διαγραφή**:
   - **Αλλαγή σειράς (Reordering)**: Εύκολη μετακίνηση επάνω/κάτω με ένα πάτημα στα βελάκια (▲/▼) ή με σύρσιμο (Drag & Drop). Η σειρά αποθηκεύεται μόνιμα.
   - **Άμεση διαγραφή από τη λίστα**: Κόκκινο κουμπί κάδου σε κάθε κάρτα, για διαγραφή **χωρίς να χρειάζεται να ανοίξετε το QR code**, με παράθυρο επιβεβαίωσης.

5. **📱 Progressive Web App (PWA)**:
   - Εγκαταστάσιμη στην αρχική οθόνη του κινητού (iOS & Android) σαν κανονική εφαρμογή.
   - Πλήρως responsive σχεδιασμός με mobile-first εργονομία.

## 🌐 Ανέβασμα στο Netlify (Deployment)

Η εφαρμογή περιλαμβάνει ήδη το αρχείο [netlify.toml](netlify.toml) με όλες τις ρυθμίσεις build και routing.

### Τρόπος 1: Μέσω GitHub (Προτεινόμενο)
1. Ανεβάστε αυτόν τον φάκελο σε ένα αποθετήριο στο **GitHub**.
2. Συνδεθείτε στο [Netlify](https://www.netlify.com/) και πατήστε **"Add new site" -> "Import an existing project"**.
3. Επιλέξτε το αποθετήριο σας. Το Netlify θα εντοπίσει αυτόματα:
   - **Build command**: `npm run build`
   - **Publish directory**: `dist`
4. Πατήστε **Deploy**. Σε λίγα δευτερόλεπτα η εφαρμογή σας θα είναι live στο δικό σας sub-domain (π.χ. `myqrs.netlify.app`).

### Τρόπος 2: Drag & Drop (Χωρίς GitHub)
1. Εκτελέστε στον υπολογιστή σας:
   ```bash
   npm run build
   ```
2. Στο Netlify, πηγαίνετε στην ενότητα **Sites** και σύρετε (drag & drop) τον φάκελο `dist` στο πλαίσιο.

## 💾 Αποθήκευση Δεδομένων: 2 Επιλογές

Δεν είστε υποχρεωμένοι να χρησιμοποιήσετε εξωτερική βάση δεδομένων. Η εφαρμογή υποστηρίζει δύο τρόπους λειτουργίας:

### Επιλογή Α: Τοπική Χρήση & Backup JSON (100% Offline - Προεπιλογή)
* **Χωρίς κανένα setup:** Τα QR codes αποθηκεύονται αυτόματα και με ασφάλεια στον browser της συσκευής σας (`LocalStorage`).
* **Μεταφορά μεταξύ συσκευών (PC ↔ Κινητό):** 
  1. Ανοίξτε το μενού **"Βάση & Backup"** (ή το γρανάζι ρυθμίσεων).
  2. Πατήστε **"Εξαγωγή JSON"** για να κατεβάσετε ένα αρχείο αντιγράφου ασφαλείας.
  3. Στη δεύτερη συσκευή, πατήστε **"Εισαγωγή JSON"** και επιλέξτε το αρχείο. Όλα τα QR σας θα εμφανιστούν αμέσως!

---

### Επιλογή Β: Αυτόματος Cloud Συγχρονισμός (Supabase - Προαιρετικό)

Αν επιθυμείτε **αυτόματο συγχρονισμό σε πραγματικό χρόνο** ώστε ό,τι σκανάρετε στο κινητό να εμφανίζεται αυτόματα και στον υπολογιστή:

1. Δημιουργήστε δωρεάν λογαριασμό στο [supabase.com](https://supabase.com) και πατήστε **New Project**.
2. Στο αριστερό μενού, ανοίξτε το **SQL Editor** και εκτελέστε το παρακάτω script:

```sql
CREATE TABLE IF NOT EXISTS public.qr_codes (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name TEXT NOT NULL,
    content TEXT NOT NULL,
    type TEXT DEFAULT 'text',
    order_index INTEGER DEFAULT 0,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);

ALTER TABLE public.qr_codes ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow public full access" ON public.qr_codes
    FOR ALL
    USING (true)
    WITH CHECK (true);

CREATE INDEX IF NOT EXISTS qr_codes_order_idx ON public.qr_codes (order_index ASC, created_at DESC);
```

3. Αντιγράψτε το **Project URL** και το **anon public key** από το *Project Settings -> API*.
4. Στην εφαρμογή σας, ανοίξτε το μενού **"Βάση & Backup"**, επικολλήστε τα στοιχεία και πατήστε **"Αποθήκευση & Σύνδεση"**.

## 🔒 Ασφάλεια Κλειδιών & GitHub

> [!IMPORTANT]
> **Μην ανεβάζετε ποτέ κλειδιά (API keys) ή αρχεία `.env` στο GitHub!**
> Το αρχείο `.gitignore` είναι ήδη ρυθμισμένο να εξαιρεί τα αρχεία `.env`.

* Αν θέλετε η εφαρμογή να συνδέεται αυτόματα στο Supabase κατά το build στο Netlify:
  1. Μπείτε στο Netlify: **Site configuration** -> **Environment variables**.
  2. Προσθέστε τις μεταβλητές:
     - `VITE_SUPABASE_URL` = το URL του Supabase project σας
     - `VITE_SUPABASE_ANON_KEY` = το anon public key
* Εναλλακτικά, **δεν χρειάζεται καν να βάλετε μεταβλητές στο Netlify**: Μπορείτε να εισάγετε τα στοιχεία μία φορά απευθείας μέσα από τη σελίδα της εφαρμογής σας (αποθηκεύονται τοπικά μόνο στον browser σας).
