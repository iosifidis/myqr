# 📱 QR Vault - Διαχειριστής & Σαρωτής QR Codes

Μια σύγχρονη, ταχύτατη και responsive Progressive Web App (PWA) εφαρμογή για σκανάρισμα, αποθήκευση, οργάνωση και διαχείριση QR codes, με **100% τοπική αποθήκευση (Offline-first)** και εύκολη μεταφορά δεδομένων (Backup/Restore).

---

## ✨ Κύρια Χαρακτηριστικά

1. **📷 Σκανάρισμα QR**:
   - Ζωντανή σάρωση με την κάμερα του κινητού ή του υπολογιστή με στόχαστρο και εφέ λέιζερ.
   - Υποστήριξη φακού (Torch/Flashlight) σε συμβατά κινητά.
   - **Άμεσο σκανάρισμα από φωτογραφία/screenshot**: Επιλογή εικόνας κατευθείαν από τη συλλογή σας.
   - Ηχητική & απτική ειδοποίηση (beep & δόνηση) κατά την επιτυχή αναγνώριση.

2. **💾 100% Τοπική Αποθήκευση & Ιδιωτικότητα**:
   - Όλα τα QR codes αποθηκεύονται αποκλειστικά στον browser της συσκευής σας (`LocalStorage`).
   - **Μηδενικό setup & πλήρης ιδιωτικότητα**: Κανένα δεδομένο δεν αποστέλλεται σε εξωτερικούς servers, και δεν απαιτούνται API keys ή λογαριασμοί σε cloud βάσεις.

3. **🔄 Μεταφορά & Αντίγραφα Ασφαλείας (JSON Backup & Restore)**:
   - **Εξαγωγή Backup (.json)**: Κατεβάστε όλα τα αποθηκευμένα QR codes σας σε ένα ενιαίο αρχείο.
   - **Εισαγωγή Backup (.json)**: Μεταφέρετε εύκολα τα δεδομένα σας από τον υπολογιστή στο κινητό (ή αντίστροφα) ανοίγοντας το αρχείο backup.

4. **📱 Mobile-First Σχεδίαση & Safe Area Ergonomics**:
   - **Όλα τα κουμπιά κάτω (Thumb Zone)**: Στα κινητά, όλες οι βασικές ενέργειες (Νέο QR, Εικόνα, Σκανάρισμα, Backup) βρίσκονται στην κάτω μπάρα πλοήγησης, εύκολα προσβάσιμες με τον αντίχειρα.
   - **Προστασία από Notch / Μπαταρία**: Πλήρης υποστήριξη Safe Area insets (`env(safe-area-inset-top)` / `env(safe-area-inset-bottom)`) ώστε κανένα κουμπί να μην επικαλύπτεται από την μπαταρία, την ώρα ή την κάμερα.

5. **📋 Διαχείριση, Προβολή & Ταξινόμηση**:
   - Δυναμική παραγωγή εικόνας QR Code σε υψηλή ανάλυση.
   - Λήψη εικόνας σε PNG (`Download`).
   - Αντιγραφή περιεχομένου (`Copy`) και άμεσο άνοιγμα συνδέσμου (`Open Link`).
   - **Αλλαγή σειράς (Reordering)**: Μετακίνηση πάνω/κάτω με ένα πάτημα στα βελάκια (▲/▼) ή με σύρσιμο (Drag & Drop).
   - **Άμεση διαγραφή**: Κουμπί κάδου σε κάθε κάρτα με παράθυρο επιβεβαίωσης.

## 🚀 Τοπική Εκτέλεση (Local Development)

```bash
# Εγκατάσταση εξαρτήσεων
npm install

# Εκκίνηση τοπικού server
npm run dev
```

Ανοίξτε το `http://localhost:5173/` στον browser σας.

## 🌐 Ανέβασμα στο Netlify (Deployment)

Η εφαρμογή περιλαμβάνει ήδη το αρχείο [netlify.toml](netlify.toml) με όλες τις ρυθμίσεις build και routing.

### Τρόπος 1: Μέσω GitHub (Προτεινόμενο)
1. Ανεβάστε αυτόν τον φάκελο στο αποθετήριό σας στο **GitHub**.
2. Συνδεθείτε στο [Netlify](https://www.netlify.com/) και πατήστε **"Add new site" -> "Import an existing project"**.
3. Επιλέξτε το αποθετήριό σας. Το Netlify θα εντοπίσει αυτόματα:
   - **Build command**: `npm run build`
   - **Publish directory**: `dist`
4. Πατήστε **Deploy**. Σε λίγα δευτερόλεπτα η εφαρμογή σας θα είναι live στο δικό σας sub-domain (π.χ. `myqrs.netlify.app`).

### Τρόπος 2: Drag & Drop (Χωρίς GitHub)
1. Εκτελέστε στον υπολογιστή σας:
   ```bash
   npm run build
   ```
2. Στο Netlify, πηγαίνετε στην ενότητα **Sites** και σύρετε (drag & drop) τον φάκελο `dist` στο πλαίσιο.
